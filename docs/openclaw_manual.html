🔄 Single Process Architecture

OpenClaw รันเป็น process เดียว (daemon) บน server ลูกค้า จัดการทุก channel พร้อมกัน ไม่ต้องรันหลาย process

🗄️ Isolated Agent Storage

แต่ละ Agent มี workspace แยกกัน เก็บ session history, memory, และ config ที่ ~/.openclaw/agents/<agentId>/

Routing Rules ทำงานยังไง

BY CHANNEL
ข้อความจาก WhatsApp เลขนี้ → Agent A
เช่น เบอร์ธุรกิจ vs เบอร์ส่วนตัว
BY GROUP
กลุ่ม Discord server นี้ → Agent B
แยก workspace ตาม team
BY SENDER
User ID นี้ → Agent C เสมอ
VIP customer ได้ agent พิเศษ
BY THREAD
Thread ที่เริ่มกับ Agent ไหน → ไปต่อกับ Agent นั้น
Context ต่อเนื่องไม่หลุด
