Phase 1
Setup — ตั้งระบบทั้งหมด
Day 1–7 · สัปดาห์แรก
Outcome
ระบบพร้อมทดสอบ
Day 1
📦 ติดตั้ง Infrastructure
  • ติดตั้ง Node.js 24 บนเครื่องตัวเอง
  • ติดตั้ง OpenClaw: npm install -g openclaw
  • รัน openclaw onboard --install-daemon
  • สมัคร Anthropic API key (claude.ai/api)
  • ทดสอบ Control UI ที่ localhost:18789
ใช้เครื่องตัวเองก่อน ไม่ต้องซื้อ VPS ตอนนี้
Day 2
💚 สมัคร LINE Official Account
  • สมัคร LINE OA ที่ manager.line.biz (ฟรี)
  • ตั้งชื่อ account ที่สื่อถึง demo เช่น "AI Demo Thai"
  • เปิดใช้งาน Messaging API
  • คัดลอก Channel Access Token + Secret
  • Webhook URL: ใส่ ngrok URL ชั่วคราว
ใช้ ngrok สำหรับ local test ก่อน
Day 3
🔗 เชื่อมต่อ LINE กับ OpenClaw
  • ติดตั้ง LINE channel ใน OpenClaw Control UI
  • ใส่ Channel Access Token + Secret
  • ทดสอบส่งข้อความจาก LINE → OpenClaw
  • ทดสอบ AI ตอบกลับ
  • แก้ bug ที่เจอ (ถ้ามี)
ถ้าติดตั้งไม่ได้ ดู docs.openclaw.ai/channels/line
Day 4
🤖 เขียน System Prompt ของ AI
  • สร้างไฟล์ AGENTS.md สำหรับ demo persona
  • กำหนดบุคลิก AI: ชื่อ น้ำเสียง ความรู้
  • ใส่ FAQ สำหรับธุรกิจตัวอย่าง (ร้านค้า)
  • ตั้ง fallback message เมื่อ AI ไม่รู้
  • ทดสอบถามหลาย scenario
ทำ demo เป็น "ร้านค้าออนไลน์" ก่อน ลูกค้าเข้าใจง่าย
Day 5
☁️ ซื้อ VPS + Deploy จริง
  • สมัคร DigitalOcean / Vultr (VPS $6/เดือน ~220 บาท)
  • สร้าง Ubuntu 22.04 droplet
  • ติดตั้ง Node.js 24 บน VPS
  • ติดตั้ง OpenClaw + daemon บน VPS
  • อัปเดต Webhook URL ใน LINE OA → IP จริง
VPS นี้เป็น demo server — ไม่ใช่ของลูกค้า
Day 6-7
🧪 ทดสอบ + Refine
  • ทดสอบ end-to-end จาก LINE จริง
  • ทดสอบกับ scenario 20+ แบบ
  • ปรับ prompt ให้ตอบได้ดีขึ้น
  • ทดสอบ handoff "ส่งต่อ staff"
  • จด bug list + แก้ทั้งหมด
เมื่อจบ Phase 1: ทักไป LINE OA แล้วได้รับตอบ AI ทันที

Phase 2
สร้าง Demo — ของที่ขายได้จริง
Day 8–14 · สัปดาห์ 2
Outcome
Demo พร้อม + Salepage
Day 8-9
🎭 สร้าง Demo Scenario 3 แบบ
  • Demo A: ร้านเสื้อผ้าออนไลน์ (ถามสต็อก/ราคา)
  • Demo B: คลินิกความงาม (นัดหมาย/ถามบริการ)
  • Demo C: โรงแรม (จองห้อง/ถามโปรโมชั่น)
  • แต่ละ demo มี FAQ 20+ ข้อพร้อมใช้
  • QR code สแกนแล้วทดลองได้เลย
ลูกค้าคลินิกทดลอง Demo B → เห็นแล้วอยากได้ทันที
Day 10
📱 ถ่ายวิดีโอ Demo 60 วินาที
  • ถ่าย screen recording + เสียงพากย์ไทย
  • แสดง: ลูกค้าถาม → AI ตอบใน 2 วินาที
  • แสดง: ถามนอกสคริปต์ AI ยังตอบได้ (Gen AI)
  • แสดง: ส่งต่อ staff เมื่อจำเป็น
  • ตัดต่อด้วย CapCut (ฟรี)
วิดีโอ 60 วินาที = conversion tool ที่ดีที่สุด
Day 11-12
📄 สร้างเอกสารขาย
  • One-pager: ปัญหา → วิธีแก้ → ราคา → CTA
  • Proposal template (Word/Canva)
  • Invoice template
  • Service agreement อย่างง่าย (1 หน้า)
  • QR code สำหรับแต่ละ demo
ทำ one-pager เป็น PDF ส่ง WhatsApp/LINE ได้เลย
Day 13-14
🌐 Setup Online Presence
  • สร้าง LINE OA หลัก (เป็น demo + รับ lead)
  • LinkedIn profile อัปเดต (ใส่ AI Specialist)
  • Facebook Page ของธุรกิจ
  • โพสต์ salepage.html บน hosting ฟรี (Netlify/GitHub Pages)
  • ใส่ QR code ทดลอง demo ใน salepage
เมื่อจบ Phase 2: มี demo ที่ลูกค้าทดลองได้ + salepage พร้อม

Phase 3
Outreach — หาลูกค้าตัวแรก
Day 15–28 · สัปดาห์ 3-4
Outcome
นัด Discovery call 3+ ราย
Day 15-16
📝 สร้าง Content ชุดแรก
  • LinkedIn post: "ผมทำ AI ตอบ LINE แทนพนักงานได้แล้ว" + วิดีโอ demo
  • Facebook post: รูป before/after + ราคา
  • TikTok: วิดีโอ demo 60 วินาที + caption ภาษาไทย
  • ตั้ง auto-reply LINE OA ให้ส่ง demo link ทันที
อย่า polish มาก — post เลย ดีกว่ารอ perfect
Day 17-18
🎯 สร้าง Prospect List
  • Google "คลินิกความงาม กรุงเทพ" → เก็บ LINE/FB 50 ราย
  • Facebook Group "ร้านค้าออนไลน์" → เก็บ contact 50 ราย
  • LinkedIn search "เจ้าของร้าน / owner / clinic manager"
  • บันทึกใน spreadsheet: ชื่อ, channel, pain point ที่เดา
  • แบ่งกลุ่ม: คลินิก 30 / ร้านค้า 30 / อื่นๆ 20
100 contacts = 10-20 replies = 3-5 calls
Day 19-21
📨 ส่ง Cold Message ชุดแรก
  • ส่ง 30 messages (Facebook Messenger / LINE)
  • ใช้ template ที่ personalized ตาม industry
  • อย่าขายตรง — ส่ง demo ให้ทดลองก่อน
  • Follow-up คนที่เปิด message แล้วไม่ตอบ (Day 3)
  • Track replies ใน spreadsheet
ดู script ด้านล่าง section "Scripts"
Day 22-24
💬 Join Facebook Groups
  • เข้าร่วม "เจ้าของธุรกิจ SME ไทย"
  • เข้าร่วม "ร้านค้าออนไลน์ไทย"
  • เข้าร่วม "คลินิก Beauty Thailand"
  • ตอบคำถามใน group (ไม่ขายตรง) build trust ก่อน
  • แชร์ insight เรื่อง AI ใน LINE OA
ห้ามขายตรงใน group — โดนแบน! ให้ DM แทน
Day 25-26
📞 เริ่ม Discovery Calls
  • นัด call กับ prospect ที่สนใจ (30 นาที)
  • เป้า: นัดให้ได้ 3+ ราย ใน Phase นี้
  • ใช้ Discovery script (ดู section Scripts)
  • ฟังมากกว่าพูด — เข้าใจ pain point ลูกค้า
  • จบ call: "ขอส่ง proposal ให้ภายใน 48 ชั่วโมงได้ไหม"
Call ผ่าน Zoom / LINE Video / โทรศัพท์ก็ได้
Day 27-28
📊 ส่ง Proposal + ติดตาม
  • ส่ง proposal PDF ที่ customize ตามลูกค้า
  • ใส่ ROI estimate ที่ specific กับ business เขา
  • ระบุ timeline ชัดเจน: เริ่ม X วันที่ Y เสร็จ
  • Follow-up ถ้าไม่ตอบใน 48 ชั่วโมง
  • เตรียมรับ objection (ดู section Objection)
เมื่อจบ Phase 3: มี proposal ส่งไปแล้ว 3+ ราย

Phase 4
ปิดดีล — Sign + มัดจำ 50%
Day 29–38 · สัปดาห์ 5-6
Outcome
Sign สัญญา + รับ 10,000 บาท
Day 29-30
🔄 Negotiation + Handle Objection
  • "แพงเกินไป" → แสดง ROI: ประหยัดค่าแรง CS เท่าไหร่/เดือน
  • "กลัวข้อมูลรั่ว" → อธิบาย self-hosted = ข้อมูลอยู่กับเขา
  • "ขอดูตัวอย่างก่อน" → ส่ง QR demo ทดลองได้เลยตอนนี้
  • "ขอคิดก่อน" → "เข้าใจครับ ขอกำหนด deadline ไหม?"
  • อย่า discount ง่าย — ให้ value เพิ่มแทน
ลูกค้าที่ "กลัวข้อมูลรั่ว" คือ lead ที่ดีที่สุดของเรา!
Day 31-32
📋 ส่งสัญญา + รอ Sign
  • ส่ง Service Agreement 1 หน้า (อ่านง่าย)
  • ระบุ: scope, timeline, payment terms, SLA
  • Payment: 50% upfront, 50% เมื่อ go live
  • ใช้ HelloSign/DocuSign (ฟรี tier) sign ออนไลน์ได้
  • หรือพิมพ์ส่ง scan กลับก็ได้
สัญญา 1 หน้า ง่ายกว่า ลูกค้า SME sign เร็วกว่า
Day 33
💰 รับมัดจำ 50% — เงินเข้าแรก!
  • ส่ง Invoice #001 พร้อม QR พร้อมเพย์
  • รับโอนเงิน 10,000 บาท (จาก deal 20,000)
  • ส่ง receipt ยืนยันรับเงินทันที
  • ส่ง "ยินดีต้อนรับ" message + timeline เริ่มงาน
  • 📌 นี่คือเงินเข้ากระเป๋าครั้งแรก!
🎉 Milestone แรก: มัดจำ 10,000 บาท
Day 34-38
📅 Kick-off + วางแผน Delivery
  • Kick-off call 30 นาที กับลูกค้า
  • เก็บข้อมูล: สินค้า, FAQ, ชื่อ brand, น้ำเสียง
  • ส่ง "Client Onboarding Form" (Google Form)
  • ตกลง timeline: เสร็จภายใน X วัน
  • ระหว่างรอ: ไป outreach ลูกค้ารายต่อไป
อย่าหยุด outreach แม้จะได้ deal แรก — pipeline ต้องเดินต่อ
🚦
Decision Gate: ก่อนรับงาน ต้องเช็คนี้
ถ้าไม่ครบทุกข้อ อย่าเพิ่งรับเงิน
Scope ชัดเจน ไม่มีคำว่า "ฯลฯ"
Payment terms ระบุในสัญญา
Timeline realistic (ไม่ใช่ฝัน)
ลูกค้ามี VPS หรือพร้อมซื้อ
ลูกค้ามี LINE OA หรือพร้อมสมัคร
Acceptance criteria ชัดเจน

Phase 5
Deliver — ติดตั้งและ Go Live
Day 39–52 · สัปดาห์ 7-8
Outcome
ระบบ Live + ลูกค้าแฮปปี้
Day 39-40
🖥️ Setup VPS ลูกค้า
  • ซื้อ VPS ให้ลูกค้า (หรือแนะนำให้ซื้อ)
  • DigitalOcean $6/เดือน = ~220 บาท
  • ติดตั้ง Ubuntu 22.04 + Node.js 24
  • ติดตั้ง OpenClaw + daemon
  • Configure firewall + SSL (Let's Encrypt ฟรี)
VPS ของลูกค้า ไม่ใช่ของเรา — ข้อมูลอยู่กับเขา
Day 41-42
🔗 เชื่อมต่อ LINE OA ลูกค้า
  • ขอ Channel Access Token + Secret จากลูกค้า
  • Configure LINE channel ใน OpenClaw
  • ตั้ง Webhook URL → domain จริงของลูกค้า
  • ทดสอบ connection ว่า message ผ่านได้
  • Setup auto-reply + greeting message
ถ้าลูกค้าไม่มี LINE OA ช่วย guide สมัครด้วย
Day 43-45
🤖 Build AI Knowledge Base
  • รวบรวม FAQ จาก Onboarding Form
  • เขียน System Prompt ตาม brand ลูกค้า
  • ใส่ข้อมูลสินค้า/บริการทั้งหมด
  • ตั้ง escalation path: AI ไม่รู้ → "รอสักครู่นะคะ"
  • ทดสอบกับ 30+ คำถามจริงที่ลูกค้าเคยได้รับ
ยิ่งข้อมูลเยอะ AI ยิ่งตอบได้ดี — ขอ FAQ เก่าจากลูกค้าด้วย
Day 46-47
🧪 UAT — ให้ลูกค้าทดสอบ
  • ส่งลิงก์ทดสอบให้ลูกค้า 2-3 คนในทีม
  • ให้ทดสอบ 3 วัน เก็บ feedback ทุกข้อ
  • แก้ทุก issue ที่ลูกค้าแจ้ง
  • ปรับ prompt ตาม feedback
  • ทดสอบซ้ำจนลูกค้า sign off
UAT = หลักฐานว่าระบบทำงานได้ก่อนรับเงินที่เหลือ
Day 48-49
📚 Training ทีมลูกค้า
  • สอน: วิธีดู Control UI dashboard
  • สอน: วิธีอัปเดต FAQ ใน AGENTS.md
  • สอน: วิธี escalate ถ้า AI ตอบผิด
  • สอน: วิธีดู conversation log
  • ส่ง User Manual PDF 5-10 หน้า
ทีมลูกค้าต้องดูแลได้เอง = ลด support load ของเรา
Day 50-52
🟢 Go Live + Monitor
  • เปิดระบบให้ลูกค้าจริงเริ่มใช้งาน
  • Monitor 48 ชั่วโมงแรกอย่างใกล้ชิด
  • ตอบ support ทันทีถ้ามีปัญหา
  • เก็บ metric: messages/วัน, % AI resolved
  • ส่ง go-live summary ให้ลูกค้า
Go live แล้ว = พร้อมรับเงินที่เหลือ!

[ฟัง] → "คำถามที่ได้บ่อยที่สุดคืออะไรครับ?"

[ถ้าตอบ 15,000-20,000] →
"งั้น AI ช่วยงานได้ 70% = ประหยัด 10,000-14,000 บาท/เดือน

"แต่ข้อดีกว่าคือ: ลูกค้าได้ตอบตลอด 24 ชั่วโมง
