คำถามที่พบบ่อย

มีคำถามอะไรบ้าง?

ต้องมีความรู้ด้าน IT ไหมถึงจะใช้ได้? ▾
ทีมงานเราดูแลการติดตั้งและ configure ให้ทั้งหมดครับ ฝั่งลูกค้าต้องมีแค่ VPS server (เราแนะนำให้ได้) และคนที่ดูแล server ได้บ้าง (basic Linux) หลังติดตั้งแล้ว การใช้งานปกติไม่ต้องมีความรู้ IT เลย มี Control UI dashboard ที่ใช้งานผ่าน browser ได้เลย
LINE API มีค่าใช้จ่ายเพิ่มเติมไหม? ▾
LINE Messaging API มีค่าใช้จ่ายของ LINE เองแยกต่างหากครับ แผน Free (1,000 messages/เดือน) ใช้ได้สำหรับธุรกิจเล็ก แผน Light (~800 บาท/เดือน) หรือ Standard (~1,500 บาท/เดือน) สำหรับ volume สูงขึ้น ค่านี้ลูกค้าจ่ายตรงกับ LINE ไม่ผ่านเรา เราจะแนะนำ plan ที่เหมาะสมให้
ถ้า VPS ล่มระบบจะเป็นอย่างไร? ▾
OpenClaw รันเป็น daemon บน VPS ครับ ถ้า VPS restart ระบบจะกลับมา auto หลังจาก restart สำหรับ Business package ขึ้นไป เรามี monitoring service ที่แจ้งเตือนเราเมื่อระบบ down และ SLA response time ตามที่ตกลง Enterprise package มี uptime guarantee 99%
AI ตอบผิดจะทำอย่างไร? มี liability ไหม? ▾
เราออกแบบระบบให้มี guardrails และ fallback ครับ เมื่อ AI ไม่แน่ใจจะ escalate ให้ทีมงานของลูกค้าโดยอัตโนมัติ ทุก deployment เราตั้งค่า confidence threshold และ human handoff trigger สำหรับธุรกิจที่มี liability สูง (คลินิก กฎหมาย) เราแนะนำให้ AI ทำ "first response" แล้ว human review ก่อน confirm
ย้าย AI Provider ได้ไหม? ถ้าราคา Claude แพงขึ้น ▾
ได้ครับ นี่คือข้อดีที่สำคัญที่สุดของ OpenClaw รองรับ 35+ LLM providers ถ้าวันนึง Claude แพงขึ้น ย้ายไปใช้ GPT-4, Gemini หรือแม้แต่ Ollama (self-hosted ฟรี) ได้ทันที ไม่ต้องเขียน code ใหม่ แค่เปลี่ยน config
"Private AI" ต่างจากแพ็กเกจปกติยังไง? ▾
Private AI ใช้ Ollama ซึ่งเป็น AI model ที่รันบน server ลูกค้าเองทั้งหมดครับ ข้อความที่ส่งเข้ามาไม่ออกอินเตอร์เน็ตเลย แม้แต่ถึง Anthropic หรือ OpenAI ก็ไม่ เหมาะมากสำหรับธุรกิจที่มี sensitive data เช่น ข้อมูลผู้ป่วย เอกสารกฎหมาย ข้อมูลทางการเงิน trade-off คือ model อาจฉลาดน้อยกว่า Claude เล็กน้อย แต่ privacy สูงสุด
