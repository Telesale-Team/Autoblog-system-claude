## 2. ข้อความ First Touch (LINE/FB DM)

**Variant A — ตรงประเด็น (ร้านที่รีวิวดีแต่จองผ่านแชท):**
> สวัสดีครับ ผมเห็นร้าน [ชื่อร้าน] รีวิวดีมากเลยครับ ลูกค้าเยอะขนาดนี้ แอดมินตอบแชทจองคิวไหวไหมครับ 😄
> ผมทำระบบให้ลูกค้ากดจองเองได้ 24 ชม. กันคิวชนอัตโนมัติ เตือนลูกค้าก่อนถึงนัดให้ด้วย — ระบบนี้มีร้านนวดที่นอร์เวย์ใช้จริงอยู่
> ลองกดเล่นดูได้เลยครับ ไม่ต้องสมัคร: booking.noodee-bootbiz.com
> ถ้าสนใจ ผมสาธิตให้ดูฟรี 20 นาทีครับ

**Variant B — เปิดด้วย pain (ร้านที่โพสต์รับจองในเพจ):**
> สวัสดีครับ เห็นเพจรับจองคิวทางแชทอยู่ อยากถามตรงๆ ครับ เคยเจอลูกค้าจองซ้อน หรือจองแล้วไม่มาไหมครับ
> ผมมีระบบที่แก้ตรงนี้ — ลูกค้าจองเองบนเว็บของร้านคุณเอง (ไม่ใช่แอปตัวกลาง ไม่มีค่าคอม) ระบบเตือนลูกค้าก่อนนัด 24 ชม. + 1 ชม. อัตโนมัติ
> ดูหน้าตาระบบจริงได้ที่ booking.noodee-bootbiz.com ครับ สนใจทักกลับได้เลย

**Follow-up วัน 3:** ส่งลิงก์ sale page + "10 ร้านแรกลดค่าติดตั้ง 50% เหลือ [X] ครับ ตอนนี้เหลือ [n] สิทธิ์"
**Follow-up วัน 7 (ครั้งสุดท้าย):** "เดี๋ยวผมไม่รบกวนแล้วครับ ฝากลิงก์ไว้ เผื่อวันไหนแอดมินลาออกแล้วไม่มีคนตอบแชท 😄 [ลิงก์]"

## 3. Demo Call Script (20 นาที)

1. **ถาม pain ก่อน (5 นาที):** ตอนนี้รับจองยังไง / เคยจองซ้อนไหม / no-show บ่อยไหม / ใครตอบแชท
2. **Demo ตาม pain (10 นาที):** เปิด booking.noodee-bootbiz.com จองให้ดูจริง 1 รอบ → โชว์ dashboard เจ้าของ (login: demo_owner / NoodeeDemo2026) → ชี้ report รายวันเข้า email
3. **ปิด (5 นาที):** แนะนำ tier ที่เหมาะ → offer 10 ร้านแรก → ถามตรง "อยากเริ่มเมื่อไหร่ครับ" → นัดวันเก็บข้อมูลร้าน (รายการบริการ/พนักงาน/เวลาเปิดปิด)

## 5. Objection Cheat Sheet

| ลูกค้าพูด | ตอบ |
|-----------|------|
| "Fresha ฟรี" | ฟรีแต่เก็บคอม ~20% ต่อลูกค้าใหม่ + ข้อมูลลูกค้าอยู่กับ platform — ของเรา flat fee ข้อมูลเป็นของร้าน 100% |
| "จองผ่าน LINE อยู่แล้ว" | LINE ใช้ต่อได้เลย แค่แปะลิงก์จองไว้ — ต่างตรงไม่ต้องมีคนตอบ ไม่จองซ้อน มี reminder อัตโนมัติ |
| "แพงไป" | เทียบค่าจ้างแอดมินตอบแชทเดือนละหมื่นกว่า หรือ no-show เดือนละ 2-3 คิวก็เกินค่าระบบแล้ว |
| "ขอคิดดูก่อน" | ได้ครับ ฝาก demo ไว้ลองเล่น + ล็อกสิทธิ์ส่วนลด 10 ร้านแรกให้ถึง [วันที่] |
| "พนักงานใช้ไม่เป็น" | ใช้บนมือถือเหมือนแอปทั่วไป เรา train ให้ฟรีตอนติดตั้ง |
