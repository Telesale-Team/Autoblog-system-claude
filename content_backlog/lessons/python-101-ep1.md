จุดสำคัญที่ต้องจำคือ **Python ทำงานจากบนลงล่าง ทีละบรรทัด** ไม่ข้าม ไม่ย้อน (จนกว่าเราจะสั่งให้มันย้อน ซึ่งจะเรียนใน EP5) ถ้าโค้ดคุณให้ผลไม่ตรงที่คิด 90% ของกรณีคือลำดับบรรทัดผิด ไม่ใช่ Python พัง

## ติดตั้ง Python ลงเครื่อง

:::step 1 เข้าเว็บทางการแล้วโหลด
เปิด `python.org/downloads` เว็บจะตรวจเครื่องคุณให้เองแล้วขึ้นปุ่มเหลืองใหญ่ว่า "Download Python 3.x.x" กดปุ่มนั้นได้เลย ไม่ต้องเลือกเวอร์ชันเอง
:::

:::step 2 เปิดไฟล์ที่โหลดมา แล้วติ๊กช่องสำคัญก่อนกด Install
หน้าแรกของตัวติดตั้งจะมีช่องเล็กๆ ข้างล่างเขียนว่า **"Add python.exe to PATH"** **ต้องติ๊กช่องนี้ก่อนเสมอ** แล้วค่อยกด "Install Now" รอประมาณ 2-3 นาที
:::

:::danger[🚫] ช่อง Add to PATH คือจุดที่คนพลาดมากที่สุดใน EP นี้
ถ้าไม่ติ๊ก เครื่องจะติดตั้ง Python สำเร็จ แต่พอคุณพิมพ์คำสั่งเรียกใช้ เครื่องจะบอกว่าหาไม่เจอ แล้วคุณจะงงมากว่าติดตั้งไปแล้วทำไมไม่มี — ถ้าเผลอกด Install ไปแล้ว ให้เปิดไฟล์ติดตั้งอีกครั้ง เลือก Modify แล้วติ๊กใหม่ได้ครับ ไม่ต้องลบทิ้ง
:::

:::step 3 เช็คว่าติดตั้งสำเร็จจริง
เปิดโปรแกรม Terminal ขึ้นมา — Windows กดปุ่ม Start พิมพ์ว่า `powershell` แล้ว Enter ส่วน Mac กด Command+Space พิมพ์ `terminal` แล้ว Enter จะได้หน้าต่างดำๆ ที่พิมพ์คำสั่งได้ พิมพ์บรรทัดนี้ลงไป
:::

```
python --version
```

ถ้าขึ้นข้อความประมาณ `Python 3.13.1` (เลขท้ายไม่ต้องตรงกับผมก็ได้) แปลว่าเรียบร้อยครับ ถ้าขึ้นว่าไม่รู้จักคำสั่ง ให้ย้อนกลับไปทำข้อ 2 ใหม่โดยติ๊ก Add to PATH

:::note[💡] Mac มี Python ติดมาอยู่แล้วนะ
แต่เป็นเวอร์ชันเก่าที่ระบบใช้เอง ให้ติดตั้งตัวใหม่จาก python.org ทับไปเลยครับ ไม่มีปัญหา และบน Mac บางเครื่องต้องพิมพ์ `python3 --version` แทน — ถ้า `python` เฉยๆ ไม่ได้ผล ให้เติม 3 ต่อท้ายทุกคำสั่งในคอร์สนี้
:::

## ติดตั้งที่ทำงานของเรา — VS Code

ทางเทคนิคคุณเขียน Python ใน Notepad ก็ได้ครับ แต่มันจะทรมานมาก เราจะใช้ VS Code ซึ่งเป็นโปรแกรมเขียนโค้ดที่ฟรี เบา และคนใช้เยอะที่สุดในโลกตอนนี้ ข้อดีคือมันจะเตือนคุณตั้งแต่ยังพิมพ์ไม่จบบรรทัดว่าตรงไหนผิด

:::step 1 โหลดและติดตั้ง
เข้า `code.visualstudio.com` กดปุ่ม Download ตัวใหญ่ ติดตั้งแบบกด Next รัวๆ ได้เลย ไม่มีอะไรต้องตั้งค่าพิเศษ
:::

:::step 2 ติดตั้งส่วนเสริมภาษา Python
เปิด VS Code → มองแถบไอคอนด้านซ้ายสุด กดรูป **สี่เหลี่ยม 4 ชิ้น** (Extensions) → ช่องค้นหาพิมพ์ว่า `Python` → ตัวแรกที่ผู้พัฒนาเป็น Microsoft กด **Install**
:::

:::step 3 สร้างโฟลเดอร์เก็บงานของคอร์สนี้
สร้างโฟลเดอร์ใหม่ในเครื่อง ตั้งชื่อว่า `python-course` (ใช้ชื่อภาษาอังกฤษ ไม่เว้นวรรค) แล้วใน VS Code เลือกเมนู File → Open Folder → เลือกโฟลเดอร์นี้ ต่อไปงานทุก EP เราจะเก็บไว้ที่นี่ที่เดียว
:::

## เขียนโค้ดบรรทัดแรก

ถึงเวลาแล้วครับ ใน VS Code กด **New File** (ไอคอนหน้ากระดาษมีเครื่องหมายบวก อยู่ตรงชื่อโฟลเดอร์ทางซ้าย) ตั้งชื่อไฟล์ว่า `hello.py` — ส่วนที่สำคัญคือ **นามสกุล .py** ซึ่งเป็นสิ่งที่บอกทุกคนว่านี่คือไฟล์ภาษา Python

พิมพ์บรรทัดนี้ลงไป **พิมพ์เองนะครับ อย่าก๊อป** จะได้เห็นว่า VS Code ช่วยเราตรงไหนบ้าง

```
print("สวัสดีครับ ผมเขียนโปรแกรมเป็นแล้ว")
```

กด Ctrl+S (Mac กด Command+S) เพื่อเซฟ แล้วรันด้วยวิธีใดวิธีหนึ่งใน 2 วิธีนี้

**วิธีที่ 1 (ง่ายสุด)** — กดปุ่ม **สามเหลี่ยม ▷** มุมขวาบนของ VS Code

**วิธีที่ 2 (แบบที่มืออาชีพใช้)** — เปิด Terminal ใน VS Code ด้วยเมนู Terminal → New Terminal แล้วพิมพ์

```
python hello.py
```

ด้านล่างจอจะขึ้นข้อความว่า

```
สวัสดีครับ ผมเขียนโปรแกรมเป็นแล้ว
```

ยินดีด้วยครับ นั่นคือโปรแกรมตัวแรกของคุณ 🎉

## มาแกะกันว่าบรรทัดนั้นแปลว่าอะไร

โค้ดบรรทัดเดียวนั้นมีของ 3 อย่างซ่อนอยู่ และทั้ง 3 อย่างนี้จะอยู่กับคุณไปตลอดคอร์ส

```
print("สวัสดีครับ ผมเขียนโปรแกรมเป็นแล้ว")
 ^^^^^ ^                            ^
  |    |                            |
  |    +-- เครื่องหมายคำพูด ครอบข้อความ
  |
  +-- ชื่อคำสั่ง แปลว่า "แสดงออกมาให้เห็น"
```

1. `print` คือ **คำสั่ง** แปลตรงตัวว่า "พิมพ์ออกมาให้เห็นบนจอ" เป็นคำสั่งที่คุณจะใช้บ่อยที่สุดในชีวิตการเขียนโปรแกรม
2. `( )` วงเล็บ คือที่สำหรับใส่ "ของที่จะให้คำสั่งนี้ทำงานด้วย" ทุกคำสั่งใน Python จะมีวงเล็บต่อท้ายเสมอ
3. `" "` เครื่องหมายคำพูด บอกว่าข้างในนี้คือ **ข้อความ** ไม่ใช่คำสั่ง — ถ้าลืมใส่ Python จะพยายามอ่านมันเป็นคำสั่งแล้วพัง

ลองเล่นต่ออีกนิดครับ เพิ่มอีก 2 บรรทัด แล้วรันใหม่

```
print("สวัสดีครับ ผมเขียนโปรแกรมเป็นแล้ว")
print("วันนี้วันแรกของการเรียน Python")
print(2026)
```

สังเกตบรรทัดสุดท้ายนะครับ — `2026` ไม่มีเครื่องหมายคำพูด เพราะมันคือ**ตัวเลข** ไม่ใช่ข้อความ เรื่องความต่างระหว่างตัวเลขกับข้อความจะเป็นพระเอกของ EP2 ครับ

## กับดักที่คุณจะเจอ

:::warn[⚠️] 1. ใช้เครื่องหมายคำพูดภาษาไทย
ถ้าคุณเผลอเปลี่ยนแป้นเป็นภาษาไทยแล้วพิมพ์ฟันหนู มันจะได้อักขระคนละตัวกัน Python จะฟ้อง `SyntaxError` ทันที — เครื่องหมายคำพูดต้องพิมพ์ตอนแป้นเป็นภาษาอังกฤษเท่านั้น
:::

:::warn[⚠️] 2. ลืมปิดวงเล็บ
`print("สวัสดี"` จะได้ error ว่า `SyntaxError: unexpected EOF` แปลว่า "อ่านจนจบไฟล์แล้วยังไม่เจอวงเล็บปิดเลย" — VS Code ช่วยได้เยอะเพราะมันใส่วงเล็บปิดให้อัตโนมัติ
:::

:::warn[⚠️] 3. ตั้งชื่อไฟล์ว่า python.py
ห้ามเด็ดขาดครับ เพราะจะไปชนกับชื่อของตัว Python เอง แล้วเกิดอาการแปลกๆ ที่หาสาเหตุยากมาก ใช้ชื่ออื่นเถอะครับ เช่น `hello.py`, `test01.py`
:::

:::warn[⚠️] 4. พิมพ์ Print แทน print
Python แยกตัวพิมพ์ใหญ่-เล็กครับ `Print` กับ `print` คือคนละตัวกัน และ Python รู้จักแค่ `print` ตัวเล็กทั้งหมด
:::

## ลงมือทำ

ทำในไฟล์ใหม่ชื่อ `ep1_practice.py` ครับ

**ข้อ 1 (ง่าย)** — เขียนโปรแกรมที่พิมพ์ชื่อร้านหรือชื่อธุรกิจของคุณ ที่อยู่ และเบอร์โทร ออกมา 3 บรรทัด

:::answer ดูเฉลยข้อ 1
```
print("ร้านกาแฟหนูดี")
print("123 ถนนสุขุมวิท กรุงเทพฯ")
print("โทร 02-123-4567")
```
:::

**ข้อ 2 (กลาง)** — ทำให้ผลลัพธ์มีเส้นคั่นสวยๆ แบบนี้ (ใบ้: `print("=" * 30)` จะพิมพ์เครื่องหมาย = ติดกัน 30 ตัว)

```
==============================
       ร้านกาแฟหนูดี
==============================
```

:::answer ดูเฉลยข้อ 2
```
print("=" * 30)
print("       ร้านกาแฟหนูดี")
print("=" * 30)
```

เคล็ดลับ: การเว้นวรรคหน้าชื่อร้านในข้อความ ใช้เพื่อดันให้อยู่กลางๆ — ยังไม่ต้องทำให้เป๊ะครับ EP3 เราจะมีวิธีที่ดีกว่านี้
:::

**ข้อ 3 (ท้าทาย)** — ลองพิมพ์ `print("สวัสดี" + "ครับ")` กับ `print("สวัสดี", "ครับ")` แล้วดูว่าผลลัพธ์ต่างกันตรงไหน อธิบายให้ตัวเองฟังได้ว่าทำไม

:::answer ดูเฉลยข้อ 3
แบบ `+` ได้ `สวัสดีครับ` (ติดกัน) เพราะเครื่องหมายบวกคือการ "ต่อข้อความเข้าด้วยกันตรงๆ"

แบบ `,` ได้ `สวัสดี ครับ` (มีเว้นวรรค) เพราะจุลภาคคือการบอก print ว่า "นี่คือของ 2 ชิ้นแยกกันนะ" แล้ว print จะใส่เว้นวรรคคั่นให้เองอัตโนมัติ
:::

## EP หน้าเจออะไร

ตอนนี้โปรแกรมของเรายัง "พูด" ได้อย่างเดียว มันยังจำอะไรไม่ได้เลย EP2 เราจะสอนให้มันจำค่าต่างๆ ไว้ในสิ่งที่เรียกว่า **ตัวแปร** แล้วเอาไปคำนวณต่อได้ ปลายทางของ EP2 คือ**เครื่องคิดเลขที่คิดกำไรร้านคุณได้จริง** ครับ
