# เกณฑ์ให้คะแนน — หน้าขาย / โฆษณา / CTA (0-100)

## 1. ความชัดใน 5 วินาทีแรก (0-25)
- คนเข้ามาเห็นแล้วรู้ไหมว่านี่คืออะไร สำหรับใคร
- พาดหัวพูดถึงผลลัพธ์ของลูกค้า ไม่ใช่ฟีเจอร์ของเรา
- ไม่ต้องเลื่อนก่อนถึงจะเข้าใจ

## 2. ความน่าเชื่อ (0-25)
- มีหลักฐานจริง เช่น ภาพหน้าจอระบบจริง ตัวเลขจริง เสียงลูกค้าจริง
- ราคาแสดงชัด ไม่ต้องทักไปถาม
- ไม่มีเคลมที่พิสูจน์ไม่ได้ ("ดีที่สุด" "ครบวงจร" "ตอบโจทย์ทุกความต้องการ")
- ถ้าเทียบคู่แข่ง ต้องเทียบด้วยข้อเท็จจริง ห้ามใส่ร้าย

## 3. ลดแรงเสียดทาน (0-25)
- ขั้นตอนถัดไปมีอันเดียวและชัดเจน
- ตอบข้อกังวลที่ลูกค้าคิดอยู่ตรงจุดที่เขาคิดพอดี
- ฟอร์มถามเท่าที่จำเป็น
- บอกว่าจะเกิดอะไรขึ้นหลังกด

## 4. เหมาะกับตลาดไทย (0-25)
- มีช่องทาง LINE ไม่ใช่มีแต่อีเมล
- ราคาเป็นบาท และสมเหตุสมผลกับ SME ไทย
- ภาษาไม่ใช่ภาษาแปล
- โหลดเร็วและใช้บนมือถือได้จริง
