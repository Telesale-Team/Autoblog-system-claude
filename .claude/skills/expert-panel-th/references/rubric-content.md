# เกณฑ์ให้คะแนน — บทความ / โพสต์ / จดหมายข่าว (0-100)

## 1. พลังของ Hook (0-25)
| ช่วง | หมายถึง |
|---|---|
| 0-5   | เปิดด้วยวลีสำเร็จรูป ไม่มีเหตุผลให้อ่านต่อ |
| 6-15  | น่าสนใจแต่ยังไม่เร่งด่วน ผู้อ่านเลื่อนผ่านได้ |
| 16-20 | มีช่องว่างความอยากรู้ หรือคำกล่าวที่สวนความเชื่อเดิม |
| 21-25 | เฉพาะเจาะจง เหนือความคาดหมาย และเป็นเรื่องของผู้อ่านคนนั้นจริง ๆ |

หักทันทีถ้าเปิดด้วย "ในยุคดิจิทัล..." หรือรูปเดียวกัน

## 2. เสียงที่เป็นคนจริง (0-25)
- อ่านแล้วเหมือนคนเขียนหรือเหมือนเครื่องเขียน
- ประโยคยาวสั้นสลับกันไหม หรือยาวเท่ากันหมดทุกประโยค
- มีตัวเลขและของจริง หรือมีแต่คำขยาย
- โทนตรงกับ `tone` ในโปรไฟล์ segment ไหม สรรพนามถูกไหม
- ลงชื่อนามปากกาตามที่ agent กำหนดหรือยัง

## 3. ความหนาแน่นของเนื้อ (0-25)
- ทุกย่อหน้ามีเหตุผลของตัวเองที่จะอยู่ตรงนั้น
- มีตัวเลขที่ระบุแหล่งได้ ไม่ใช่ตัวเลขลอย
- อ่านจบแล้วทำอะไรได้เพิ่มขึ้นจริงหรือแค่รู้เพิ่ม
- ตัดออก 30% แล้วเสียอะไรไปไหม ถ้าไม่เสีย = ยังหลวม

## 4. โอกาสถูกส่งต่อและ SEO (0-25)
- มีเหตุผลให้คนส่งให้เพื่อนไหม
- CTA ชวนให้ตอบจริง หรือเป็นประโยคปิดสำเร็จรูป
- keyword หลักอยู่ใน title, H1, ย่อหน้าแรก, และ H2 อย่างน้อยหนึ่งอัน
- keyword ไม่ถูกยัดจนอ่านไม่ลื่น
- มีภาพประกอบทุก H2 พร้อม alt text ที่มี keyword
