# เกณฑ์ให้คะแนน — กลยุทธ์ / บทวิเคราะห์ / ข้อเสนอแนะ (0-100)

## 1. ตั้งโจทย์ถูกหรือเปล่า (0-25)
- ระบุปัญหาที่แท้จริง ไม่ใช่อาการของปัญหา
- บอกได้ว่าอะไรอยู่นอกขอบเขต
- สมมติฐานถูกเขียนออกมาให้เห็น ไม่ได้ซ่อนไว้

## 2. หลักฐานรองรับ (0-25)
- ทุกข้ออ้างสำคัญมีแหล่งที่ตรวจสอบได้ ระบุผู้จัดทำและปี
- แยกชัดระหว่าง "ข้อมูลจริง" กับ "การตีความของเรา"
- ตัวเลขที่หาไม่ได้ถูกบอกตรง ๆ ว่าหาไม่ได้ ไม่ใช่เดาแล้วเขียนเหมือนรู้

## 3. เอาไปทำได้จริง (0-25)
- มีขั้นตอนถัดไปที่ระบุผู้รับผิดชอบและกรอบเวลา
- ประเมินต้นทุนและกำลังคนตามความเป็นจริงของธุรกิจขนาดนี้
- บอกว่าจะวัดผลอย่างไรและเมื่อไหร่จะรู้ว่าผิด

## 4. ซื่อสัตย์เรื่องความเสี่ยง (0-25)
- บอกข้อเสียและกรณีที่ไม่ควรทำ
- มีทางเลือกอื่นที่พิจารณาแล้วและเหตุผลที่ไม่เลือก
- ไม่รับปากผลลัพธ์ที่ควบคุมไม่ได้
