# เกณฑ์ให้คะแนน — Diagram / Infographic / ภาพปก (0-100)

## 1. สื่อความเข้าใจ (0-25)
- ดูแล้วเข้าใจโดยไม่ต้องอ่านคำอธิบายในบทความ
- ลำดับการอ่านชัดเจน ตาไปทางเดียวกันทั้งภาพ
- ข้อมูลในภาพตรงกับเนื้อหาในหัวข้อนั้นจริง

## 2. ตรงกับแบรนด์และ segment (0-25)
- พื้นกรม `#0F172A` และทอง `#C9A84C` **ไม่ถูกเปลี่ยน**
- ความโค้งมุมและความหนาเส้นตรงกับโปรไฟล์ segment
- สีรองของ segment ใช้เน้นจุดเดียว ไม่ได้กลายเป็นสีหลัก
- ภาพปกมีหนูดีตรงสเปก ไม่มีแถบกลางภาพ brand tag เป็น "Noodee BootBiz"

## 3. อ่านออกจริง (0-25)
- ตัวหนังสือไทยไม่ถูกตัดหรือทับกัน
- อ่านออกตอนย่อเหลือความกว้าง 400px (ขนาดที่คนเห็นจริงบนมือถือ)
- คอนทราสต์พอสำหรับคนสายตาไม่ดี

## 4. ครบตามมาตรฐานไฟล์ (0-25)
- WebP · diagram ≤ 200KB · ปก ≤ 150KB
- ชื่อไฟล์มี keyword slug
- มี alt text ที่มี keyword และบรรยายภาพจริง
- ปกขนาด 1200x630
