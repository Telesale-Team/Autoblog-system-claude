# เกณฑ์ให้คะแนน — บทเรียน / คอร์ส / คู่มือ (0-100)

## 1. จบแล้วทำอะไรได้ (0-25)
- บอกได้ชัดตั้งแต่ต้นว่าจบตอนนี้แล้วทำอะไรเป็น
- จบด้วยสิ่งที่ผู้เรียนสร้างได้จริงหนึ่งอย่าง
- ถ้าตอบไม่ได้ว่า "จบแล้วทำอะไรได้" = ตกข้อนี้ทันที

## 2. ไล่ลำดับถูก (0-25)
- ไม่ใช้สิ่งที่ยังไม่เคยสอนมาก่อน
- บอกว่าต้องผ่านตอนไหนมาก่อน
- ความยากไต่ขึ้นทีละขั้น ไม่กระโดด

## 3. ตัวอย่างใช้ได้จริง (0-25)
- ตัวอย่างมาจากธุรกิจจริง ไม่ใช่ foo/bar
- **โค้ดทุกชิ้นถูกรันจริงแล้ว** และผลลัพธ์ในบทเรียนตรงกับที่รันได้จริง
- ชื่อตัวแปรเป็นอังกฤษ คอมเมนต์เป็นไทย

## 4. กันคนหลงทาง (0-25)
- เตือนกับดักที่ผู้เริ่มต้นจะเจอ ก่อนที่เขาจะเจอ
- มีแบบฝึกหัดง่าย/กลาง/ยาก พร้อมเฉลยที่พับซ่อนได้
- มีเช็กลิสต์ให้ตรวจเองว่าผ่านจริง
- บอกว่าตอนหน้าเจออะไร
