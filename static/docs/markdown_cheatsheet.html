สูตร Markdown สำหรับเขียนบทเรียน

ใช้เมื่อ รูปแบบการเขียน = Markdown เท่านั้น — พิมพ์ในช่อง "เนื้อหา (Markdown)" ระบบจะแปลงเป็น HTML ให้อัตโนมัติทุกครั้งที่กดเซฟ

ทำไมไม่ใช้ CKEditor — CKEditor เป็น WYSIWYG จึงลบแท็กที่มันไม่รู้จักทิ้ง (กล่องเตือน, ขั้นตอน, ไดอะแกรม SVG หายหมด) บทเรียนของเราเป็นเนื้อหาที่มีโครงสร้าง เลยต้องเขียนด้วย Markdown แทน

1. พื้นฐาน — จำแค่ 6 อย่างนี้ก็เขียนได้แล้ว

พิมพ์แบบนี้ได้ผลแบบนี้
## หัวข้อใหญ่หัวข้อ H2 — ขึ้นในสารบัญอัตโนมัติ
### หัวข้อย่อยหัวข้อ H3 — ขึ้นในสารบัญเหมือนกัน
**ตัวหนา**ตัวหนา (ใช้เน้นคำสำคัญ)
`โค้ดสั้น`โค้ดในบรรทัด เช่น ชื่อคำสั่ง ชื่อไฟล์
- รายการbullet list
1. รายการnumbered list

ย่อหน้าใหม่ = เว้นบรรทัดว่าง 1 บรรทัด ระหว่างข้อความ ถ้าไม่เว้นจะกลายเป็นย่อหน้าเดียวกัน

2. โค้ดบล็อก

ครอบด้วย backtick 3 ตัว ใส่ชื่อภาษาต่อท้ายอันเปิด — ได้ปุ่ม Copy อัตโนมัติ

```python
price = 250
print(f"ราคา {price:,.2f} บาท")
```
ข้อดีสำคัญ — ในโค้ดบล็อก ระบบจะไม่แตะอะไรเลย เครื่องหมายคำพูดจะไม่ถูกแปลงเป็นอัญประกาศโค้ง ซึ่งเป็นปัญหาที่ทำให้โค้ดที่สอนไปแล้วรันไม่ได้ตอนใช้ WYSIWYG

3. กล่องพิเศษ (ของเราเอง) — ใช้ :::

ทุกกล่องเปิดด้วย :::ชนิด หัวข้อ และปิดด้วย ::: บรรทัดเดียวโดดๆ

คำสั่งใช้ตอนไหน
:::goalกล่องเป้าหมาย "จบ EP นี้ทำอะไรได้" (ไอคอน 🎯)
:::tipเคล็ดลับ ของแถม ทางลัด (ทอง)
:::noteข้อมูลเสริม รู้ไว้ก็ดี (ฟ้า)
:::warnคำเตือน ระวังพลาด (ส้ม)
:::dangerกับดักร้ายแรง ห้ามทำ (แดง)
:::analogy 🍳เปรียบเทียบให้เห็นภาพ (ใส่อิโมจิต่อท้าย)
:::step 1 หัวข้อสอนทีละขั้น มีเลขวงกลม
:::checklistเช็คลิสต์ติ๊กถูก (ข้างในใช้ -)
:::answer ดูเฉลยกล่องเฉลยแบบพับซ่อน กดแล้วค่อยเห็น
:::figure คำบรรยายรูปหรือไดอะแกรม (วาง <svg> หรือ ![](url) ข้างใน)
เขียนแบบนี้
:::warn ระวังตรงนี้
`input()` คืนค่าเป็น**ข้อความ**เสมอ
ต้องครอบด้วย `int()` ก่อน
:::
ได้กล่องเตือนสีส้ม พร้อมไอคอน ⚠️
<div class="callout c-warn">
  <span class="ico">⚠️</span>
  <div class="callout__body">
    <span class="ttl">ระวังตรงนี้</span>
    ...
</div>

เปลี่ยนไอคอนเองได้ ด้วยวงเล็บเหลี่ยม — :::tip[💰] ประหยัดเงินได้

กล่องซ้อนกันได้ เช่น ใส่ :::warn หรือโค้ดบล็อกไว้ข้างใน :::answer

บทนำสั้นๆ 3-4 บรรทัด เล่าปัญหาจริงที่คนอ่านเจอ

:::goal จบ EP นี้คุณจะทำอะไรได้
เขียนลูปได้ · สรุปยอดขาย 50 บิลได้ใน 1 วินาที

**ใช้เวลา:** อ่าน 15 นาที + ลงมือทำ 25 นาที · **ต้องผ่านมาก่อน:** EP4
:::

**ทบทวน 30 วินาที** — EP4 เราเรียนเงื่อนไข `if` มาแล้ว

## ลูปคืออะไร

:::analogy 💵
เหมือนนับเงินในลิ้นชัก — หยิบทีละใบ บวกไปเรื่อยๆ จนกว่าจะหมด
:::

```python
bills = [250, 180, 420]
total = 0
for bill in bills:
    total = total + bill
print(total)
```

:::danger ลืมย่อหน้า
บรรทัดในลูปต้องเว้น 4 ช่อง ไม่งั้นได้ `IndentationError`
:::

5. ข้อควรรู้

เรื่องรายละเอียด
วาง HTML ได้ เขียน <svg> หรือ HTML ตรงๆ ลงไปได้เลย ระบบไม่ลบทิ้ง (ต่างจาก CKEditor) — คั่นด้วยบรรทัดว่างก่อนและหลัง
ช่อง "เนื้อหา" ถูกล็อก พอตั้งเป็น Markdown แล้ว ช่อง CKEditor จะกลายเป็นอ่านอย่างเดียว เพื่อกันการเผลอเปิดแล้วเซฟทับ — ต้นฉบับอยู่ที่ช่อง Markdown เท่านั้น
สารบัญอัตโนมัติ สร้างจาก ## และ ### ให้เอง ไม่ต้องเขียนเอง (เฉพาะบทความที่ตั้ง layout = คู่มือ / Docs)
ต้นฉบับสำรอง ไฟล์ .md ของทุกบทเรียนเก็บไว้ที่ content_backlog/lessons/ ในโปรเจกต์ด้วย
ลืมปิด ::: ระบบปิดให้เองตอนจบบทความ ไม่พัง แต่กล่องอาจกินเนื้อหายาวกว่าที่ตั้งใจ
